- Writing Terraform configurations using **HCL**.
- Configuring the AzureRM provider and managing Azure resources.
- Provisioning Resource Groups, Virtual Networks, subnets and storage resources.
- Using Terraform workflow: `init`, `fmt`, `validate`, `plan`, `apply` and `destroy`.

- Working with input variables, outputs, locals and resource dependencies.
- Understanding infrastructure drift, imports and environment-specific configurations.
- Automating infrastructure deployment through Azure DevOps and GitHub Actions.
